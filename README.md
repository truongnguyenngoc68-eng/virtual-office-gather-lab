# Virtual Office & Gather Multiplayer Lab (`research-stage0`)

Bộ dự án nghiên cứu văn phòng ảo 2D Multiplayer (Gather / TheGathering) kèm kịch bản kiểm thử đồng bộ nhiều trình duyệt.

## Cấu trúc thư mục
- `Gather/` — Dự án Gather 2D (`client` + `server` Socket.IO)
- `TheGathering/` — Dự án TheGathering (Phaser 3 + React + WebRTC / Colyseus / Socket backend)
- `test-multiplayer.mjs` — Script kiểm thử kết nối multiplayer
- `test-browsers.mjs` — Script tự động mở nhiều phiên trình duyệt kiểm thử đồng bộ nhân vật
